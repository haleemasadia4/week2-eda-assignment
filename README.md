## Assignment Title

## Dataset

**World Happiness Report (2015–2019)**

The dataset was downloaded from Kaggle using **KaggleHub** and contains global happiness indicators such as GDP, Social Support, Health, Freedom, Generosity, and Perceptions of Corruption. Data from five different years was merged into a single dataset for analysis.

---

## Objectives

The objective of this project is to:

- Diagnose missing values in the dataset.
- Apply appropriate missing value imputation techniques.
- Detect and analyze outliers using statistical methods.
- Perform advanced exploratory data analysis (EDA).
- Understand introductory SQL concepts for data analysis.

---

## Tasks Completed

- Downloaded dataset using KaggleHub
- Merged multiple yearly datasets
- Cleaned and standardized column names
- Diagnosed missing values
- Applied missing value imputation
- Detected outliers using the IQR method
- Detected outliers using the Z-Score method
- Compared different outlier detection techniques
- Performed 22 Advanced EDA commands
- Created visualizations using Matplotlib and Seaborn
- Answered introductory SQL research questions

## Key Findings

- Countries with higher GDP generally report higher happiness scores.
- Health and Social Support show a positive relationship with Happiness Score.
- Outlier analysis showed that extreme happiness scores represent genuine observations rather than data errors, so they were retained for analysis.
